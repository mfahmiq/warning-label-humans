An entry for the [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty on [make.fun](https://make.fun/r/fntpv568) — the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The entry

> WARNING: This human contains no off switch. Do not attempt to reason with it after midnight.

92 characters. One label, one joke, and the laugh lands in the last few words — exactly where a real warning label puts its sting.

## Why it works

The judge weighs five things, most important first: it must be a warning label for humans that is actually funny; the laugh must land in one read with the turn in the last few words; it must feel true about people in general; it must sound like a real printed label; and it must stay inside 160 characters with no filler.

This line scores on all five. "WARNING:" and "Do not attempt to reason with it" are the exact wording and rhythm of a printed safety label. The claim is recognisably true — every human really does run with no off switch, and everyone has learned the hard way that reasoning with one after midnight goes nowhere. The turn arrives at the very end, in "after midnight", so the whole line reads straight and then lands.

## How it works

`main.py` is Python 3.13 standard library only, with no network access. It writes the single label line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and asserts the 1–160 character bound before writing. Running it twice produces byte-identical output.
